# FireStreak — Telegram bot

MVP бота для взаимных огоньков между двумя пользователями.

## Возможности
- Персональные приглашения по deep-link и подтверждение вторым участником.
- Личный список огоньков.
- Ежедневное подтверждение активности обоими участниками.
- Календарные сутки в настроенном часовом поясе.
- Напоминания в 18:00 и 23:00.
- Сброс серии после пропущенного дня.
- Топ-3 по текущей серии и топ-3 по количеству совместных дней.
- SQLite для простого запуска.

## Важное ограничение Telegram
Обычный Telegram Bot API не позволяет боту читать личную переписку двух пользователей. Поэтому этот MVP использует ежедневные добровольные отметки. Рейтинг активности считает совместные дни подтверждения, а не количество сообщений. Не выдавайте эти показатели за статистику реальной переписки.

## Запуск
1. Создайте бота через @BotFather и получите новый токен.
2. Скопируйте `.env.example` в `.env` и вставьте токен в `BOT_TOKEN`.
3. Установите Python 3.10+.
4. Установите зависимости: `pip install -r requirements.txt`.
5. Запустите: `python bot.py`.

Бот должен быть запущен постоянно на сервере/VPS. SQLite-файл хранится рядом с приложением.

## Достижения
В следующем этапе можно добавить выдачу визуальных наград на 10, 30, 50, 100, 200, 300, 400 и 500 дней, а также отдельную таблицу истории достижений.
