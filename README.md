# FrozitTest — Telegram-бот с приветствием 💗

Небольшой Telegram-бот на Python и aiogram 3.

## Возможности

- На команду `/start` отвечает: «Привет, [имя], рады тебя видеть! ♡»
- Отправляет настроенный анимированный стикер-сердечко.
- Если стикер ещё не настроен, отправляет обычное 💗.
- Если отправить боту стикер, он покажет его `file_id` для настройки.

> Важно: это отдельный анимированный стикер, а не Premium Custom Emoji внутри строки текста. Для настоящего Custom Emoji действуют ограничения Telegram.

## Установка

Требуется Python 3.10 или новее.

```bash
python -m venv .venv
```

Активируй виртуальное окружение:

**Windows**
```powershell
.venv\Scripts\Activate.ps1
```

**Linux / macOS**
```bash
source .venv/bin/activate
```

Установи зависимости:

```bash
pip install -r requirements.txt
```

Создай локальный файл `.env` на основе `.env.example` и заполни:

- `BOT_TOKEN` — новый токен, полученный у @BotFather.
- `STICKER_FILE_ID` — необязательно на первом запуске.

Запусти:

```bash
python bot.py
```

## Как добавить анимированное сердечко

1. Запусти бота.
2. Отправь ему анимированный стикер-сердечко из Telegram.
3. Бот ответит его `file_id`.
4. Скопируй значение в локальный `.env`:

```env
STICKER_FILE_ID=твой_file_id
```

5. Перезапусти бота.

Бот сможет повторно отправлять этот стикер по `file_id`. Подойдут стикеры, которые Telegram Bot API разрешает отправлять ботам.

## Безопасность

- Не публикуй токен бота в GitHub, сообщениях или скриншотах.
- Если токен уже попал в публичный чат или репозиторий, отзови его через @BotFather командой `/revoke` и используй новый.
- Файл `.env` исключён из Git через `.gitignore`.
